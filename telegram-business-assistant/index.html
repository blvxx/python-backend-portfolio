Telegram Business Assistant

A structured enquiry workflow for small businesses: visitors choose a service, share a contact, describe the task and receive confirmation. The application persists leads and can notify a responsible administrator.

Inspect source code ↗Read setup guide ↗
Functional MVP · live Telegram deployment requires a private bot token

Workflow and state

aiogram router with explicit consent, service selection, contact capture, validation, cancellation and a confirmation path.

Persistence and notifications

SQLite stores each lead with a UTC timestamp. Optional admin chat notifications and a restricted /leads command complete the routing path.

Validation and safety

Phone/email checks, bounded request length, parameterized SQL, HTML escaping and environment-based secret management.

Quality checks

pytest covers the data layer and validation boundaries without requiring a Telegram token or network access. GitHub Actions runs the suite.

Request lifecycle

01Consent
02Service selection
03Contact and details
04SQLite + admin alert
Scope: this repository contains a runnable MVP. It is not yet connected to a live public bot, CRM, payment provider or external AI model. For a real deployment, configure a bot token and administrator IDs as environment secrets, confirm the business privacy notice and choose persistent hosting.
